# soloxarc.github.io

Personal website, published with GitHub Pages at https://soloxarc.github.io.

Plain HTML and CSS with no build step:

- `index.html` holds the content (about, projects, contact). Text in `[brackets]` is placeholder.
- `style.css` holds the styling, including an automatic dark mode.

To preview locally, open `index.html` in a browser, or run `python3 -m http.server` and visit http://localhost:8000.
